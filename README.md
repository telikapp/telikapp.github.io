# telikapp.github.io

The website of [Telik](https://github.com/telikapp/telik): the iPhone remote, keyboard, AirPlay and Apple Home for
Android TV.

Plain HTML and CSS, without a build step. GitHub Pages serves the `main` branch at https://telikapp.github.io/.

- `index.html`, `ru/index.html`: the product page in English and Russian.
- `privacy.html`, `ru/privacy.html`: the privacy policy.
- `style.css`: the styles of all pages.
- `assets/og.jpg`, `assets/og-ru.jpg`: the Open Graph pictures.

The pictures on the page are HTML and CSS drawings with sample data. The page loads no files from other sites.
